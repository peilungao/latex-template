I personally use 方正字体集 as my default chinese fonts. All fonts listed must first be installed and activated before they can be used.


For windows, the [windows font settings](windows-simplified-chinese.tex) is specifically for *wsl* usage, and one argument, which links the windows font vault to the linux one, must first be executed:
`sudo ln -s /mnt/c/Windows/Fonts /usr/share/fonts/windows`
